================================================================================
STEP-BY-STEP IMPLEMENTATION ROADMAP (OPTIMIZED FOR 100% FREE TIER)
================================================================================

--------------------------------------------------------------------------------
PHASE 1: Project Setup & Package Management (uv)
--------------------------------------------------------------------------------
1. Initialize repository with `uv init backend`.
2. Configure `pyproject.toml` with:
   - `langchain`, `langgraph`, `langchain-google-genai`
   - `fastapi`, `uvicorn[standard]`, `pydantic`, `python-multipart`
   - `sqlalchemy`, `asyncpg`
   - `pytest`, `pytest-asyncio`, `ruff`
   - `langfuse` (free tier observability)
3. Create `.env.example`:
   - `GEMINI_API_KEY=` (From Google AI Studio - Free)
   - `DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/shopping_db`
   - `LANGFUSE_PUBLIC_KEY=` / `LANGFUSE_SECRET_KEY=` (Optional free cloud tracing)
4. Verify environment with `uv sync`.

--------------------------------------------------------------------------------
PHASE 2: PostgreSQL Database & Tailored Catalog Seeding
--------------------------------------------------------------------------------
1. Create `docker-compose.yml` for local PostgreSQL 16 (port 5432).
2. Define SQLAlchemy models:
   - `Product`: id, name, category, price, is_organic (bool), stock, image_url.
   - `Order`: id, user_id, items (JSONB), total_amount, status, created_at.
   - `UserPreference`: user_id, prefers_organic (bool), max_price_limit (float), notes.
3. Write `scripts/seed_db.py`:
   - Seed products specifically crafted to test constraints:
     * Organic Raw Wildflower Honey ($14.99) vs Standard Clover Honey ($6.99)
     * Organic Rolled Oats ($4.50) vs Premium Imported Manuka Honey ($35.00 - above $20 cap)
     * Gluten-free snacks, dairy-free milk, pantry staples.
   - Seed past orders for User ID 1 (e.g. bought organic honey 10 days ago).

--------------------------------------------------------------------------------
PHASE 3: Database Services & LangChain Tools
--------------------------------------------------------------------------------
1. Service functions:
   - `search_products(query, is_organic, max_price, category)`
   - `get_order_history(user_id)`
   - `save_user_preference(user_id, prefers_organic, max_price_limit, notes)`
2. Wrap as LangChain `@tool`s with strict Pydantic docstrings:
   - Parameter types, defaults, and field descriptions clearly stated so Gemini
     calls them with 95%+ zero-shot accuracy.

--------------------------------------------------------------------------------
PHASE 4: Two-Tier Zero-Cost Guardrails & Security
--------------------------------------------------------------------------------
1. **Tier 1 (Fast & Free): `guardrails/rules.py`**:
   - Regex patterns for non-shopping intents (poems, stories, coding questions, weather).
   - Prompt injection patterns ("ignore previous instructions", "system prompt reveal").
   - Execution time: < 1ms, Cost: $0.
2. **Tier 2 (Borderline Queries): `guardrails/input_classifier.py`**:
   - Small Gemini prompt with structured output: `GuardrailDecision(is_shopping, reason)`.
   - Only executed if Tier 1 is ambiguous.
3. **Tier 3 (Anti-Hallucination Output Validator): `guardrails/output_validator.py`**:
   - Pure code validator!
   - Parses product IDs or names returned by the agent and verifies they exist in PostgreSQL.
   - Validates that returned items obey the user's budget and organic preferences.
   - Enforces numbered list format compliance required by exercise prompt.

--------------------------------------------------------------------------------
PHASE 5: Multimodal LangGraph Agent
--------------------------------------------------------------------------------
1. `AgentState`:
   - `messages`, `user_id`, `active_preferences`, `image_data`, `guardrail_status`.
2. Dynamic Prompt Injection:
   - Reads `user_preferences` from PostgreSQL and dynamically adds to system instructions:
     *"User Alex always prefers organic items and has a $20 price cap unless specified."*
3. Multimodal Image Ingestion:
   - Handles base64 encoded user photos (e.g., photo of a cereal box or snack).
   - Gemini 1.5 Flash inspects image -> extracts product keywords -> invokes `search_products`.
4. Graph Assembly:
   - `entry_point` -> `rule_guardrail` -> (if passed) `agent` <-> `tools` -> `output_validator` -> `END`.

--------------------------------------------------------------------------------
PHASE 6: FastAPI Backend
--------------------------------------------------------------------------------
1. Endpoints:
   - `POST /api/chat` — accepts message, user_id, optional image file; returns Server-Sent Events (SSE).
   - `GET /api/products` — catalog list with category/price filters.
   - `GET /api/orders/{user_id}` — past order receipts.
   - `GET/POST /api/users/{user_id}/preferences` — view and edit saved preferences.

--------------------------------------------------------------------------------
PHASE 7: Evaluation Suite (Built for Free Tier Rate Limits)
--------------------------------------------------------------------------------
1. **Free / 0-LLM-Call Tests (`tests/test_guardrails_fast.py`, `test_unit_api.py`)**:
   - 20 regex and security tests for jailbreaks and off-topic questions.
   - FastAPI endpoint integration tests using `httpx.AsyncClient`.
   - Output validator anti-hallucination tests.
2. **Tool Call Accuracy Evals (`tests/test_tool_accuracy.py`)**:
   - 10-15 golden test cases:
     * "organic honey under $20" -> `search_products(query="honey", is_organic=True, max_price=20)`
     * "what did I order previously?" -> `get_order_history(user_id=1)`
     * "I never want items over $15" -> `save_user_preference(max_price_limit=15)`
   - Built-in 4-second delay between tests to respect Gemini's 15 RPM free limit.
3. **Response Quality Eval**:
   - Scores responses on: Relevance (1-5), Correctness (DB matched), Format Compliance (Numbered list).

--------------------------------------------------------------------------------
PHASE 8: Frontend (Next.js + Tailwind CSS)
--------------------------------------------------------------------------------
1. Modern Storefront UI:
   - Hero header with Cart badge and User Profile selector.
   - Interactive product grid with category filter tags and organic badges.
   - Floating AI Shopping Assistant drawer with real-time streaming text.
   - Multimodal photo upload button (drag & drop / camera).
   - Live preferences badge showing active AI memory.

--------------------------------------------------------------------------------
PHASE 9: CI/CD Pipeline & GitHub Actions (Quota-Safe)
--------------------------------------------------------------------------------
1. **PR Workflow (`.github/workflows/ci-pr.yml`)**:
   - Runs on every Pull Request.
   - Uses uv for sub-30-second package install.
   - Runs Ruff linter + 0-cost unit tests + fast guardrail tests.
   - Consumes **0 LLM API calls** (no quota wasted on PRs).
2. **Nightly / Manual Workflow (`.github/workflows/eval-nightly.yml`)**:
   - Runs the full tool-call accuracy eval suite against Gemini API.
   - Outputs a summary table: Tool-Call Accuracy %, Guardrail Pass %, Latency.
